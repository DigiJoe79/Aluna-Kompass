# Erscheinungsbild

Ein Theme sind die Farben und Schriften von Kompass: Hell und Dunkel, die
Vereinsfarbe, Flächen und Linien. Das mitgelieferte Theme ist
schreibgeschützt; eine Kopie davon können Sie ändern, prüfen lassen, ob
Kontraste ausreichen, und aktivieren.

## Ein eigenes Theme

„Duplizieren“ am Default-Theme erzeugt eine Kopie mit eigenem Namen und
Schlüssel. Darin ändern Sie Werte je Token — die Vereinsfarbe, Flächen,
Linien, Schrift — getrennt für Hell und Dunkel. Die Live-Vorschau rechts
zeigt Navigation, Knöpfe, Marken, ein Feld und eine Tabelle im neuen Theme;
genau die Kombination, an der Kontrastfehler auffallen.

Jedes Theme enthält alle Werte vollständig — es erbt nichts. Ein Theme, das
einmal gut aussieht, sieht nach einem Update noch genauso aus.

## Kontrast

Unter der Vorschau prüft Kompass jedes Farbpaar, das Text trägt, gegen die
Mindestanforderung für lesbaren Text und warnt, wo sie unterschritten ist.
Speichern geht trotzdem — aktivieren Sie ein Theme mit Warnungen aber nicht
für alle, ohne es gesehen zu haben.

## Aktivieren und löschen

„Aktivieren“ schaltet das Theme für alle Nutzer; wer Dunkel eingestellt hat,
bekommt die dunkle Hälfte. Gelöscht werden darf jedes Theme außer dem
aktiven und dem Default.

Was ein Theme **nicht** ist: die Webseite. Deren Aussehen bestimmt das
Template; das Theme gilt für Kompass selbst und für die Dokumente, die
Kompass erzeugt.
